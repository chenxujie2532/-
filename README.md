# 铁穹 FRONTLINE · 坦克大战

基于 HTML5 Canvas 2D 的纯静态坦克大战游戏，无外部资源依赖。

## 在线游玩

https://chenxujie2532.github.io/-/

## 内容

- 10 关战役、普通对战、阵地防守、资源抢夺、三阶段 BOSS
- 5 类常规敌军、3 档难度、晴雨雪雾动态天气
- 主炮射击、战术冲刺、补给道具、升级与多周目
- 本地存档、JSON 备份、本地排行榜、触屏操作

## 操作

WASD / 方向键移动；鼠标瞄准；左键 / 空格射击；Shift 冲刺；Esc / P 暂停。

触屏使用摇杆、开火和冲刺按钮。界面右上角提供完整操作指南。

## 本地运行

下载仓库并用浏览器打开 index.html 即可，无需安装或构建。

## 部署

GitHub Pages 使用 main 分支根目录发布；.nojekyll 表示直接发布静态文件。

## 存档说明

存档只保存在当前浏览器的当前网站来源中。离线版本与在线版本不会自动共享存档；请使用游戏内的导出 / 导入功能迁移。排行榜也是本地记录，不是在线共享排行榜。

## 性能边界

逻辑固定 60 Hz，绘制跟随浏览器帧时钟。实际性能受设备、浏览器和系统负载影响；不承诺所有设备恒定帧率或绝对零缺陷。
